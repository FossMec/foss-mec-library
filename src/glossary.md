# Glossary

Short definitions for terms used across the library. Add a term by editing the table in
alphabetical order — no new chapter or `SUMMARY.md` change is needed.

| Term | Meaning |
| --- | --- |
| **Branch** | A named line of commits. Branches let you work on a change without affecting `main`. |
| **Clone** | A local copy of a Git repository, including its history. |
| **Commit** | A recorded snapshot of the staged changes, with an author, timestamp and message. |
| **Fork** | Your own copy of someone else's repository on GitHub. You can change it without affecting the original. |
| **Git** | The version-control program that records changes locally. |
| **GitHub** | A hosting and collaboration platform for Git repositories, issues and pull requests. |
| **HEAD** | The commit currently checked out in your working copy. |
| **Issue** | A GitHub discussion item used to report a bug, suggest a resource or request a topic. |
| **`main`** | The default branch of this repository. Changes reach it through pull requests. |
| **Markdown** | A plain-text formatting language using `#` headings, lists and links. All library pages are Markdown. |
| **mdBook** | The static-site generator that turns `src/SUMMARY.md` and Markdown files into this website. |
| **Merge** | Combining the history of one branch into another. |
| **Merge conflict** | A state where Git cannot combine two changes automatically because they touch the same lines. |
| **Origin** | The default name for the remote repository you cloned from, usually your fork. |
| **Pull request (PR)** | A GitHub request to merge a branch into another branch, with review and automated checks. |
| **Remote** | A named copy of a repository hosted elsewhere, such as `origin` or `upstream`. |
| **Repository (repo)** | A project folder tracked by Git, including its history in `.git/`. |
| **Staging area** | The draft of the next commit; files enter it with `git add`. |
| **Upstream** | The canonical project repository that you fork from, usually `FossMec/foss-mec-library`. |
| **Working tree** | The files currently on disk that you are editing. |
