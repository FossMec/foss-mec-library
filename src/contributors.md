# Contributors

This library exists because people contribute documentation, code, design, review and workshop
material. This page lists **real, verified people only**. There are no placeholder names, and
automated bots are not presented as human contributors.

## How this page is maintained

- A maintainer adds a row after a person's **first merged contribution**.
- Credit is for merged work: documentation, code, design, review or workshop facilitation.
- Use the name and link the contributor prefers. Ask before adding a personal name.
- A contributor can request a correction or removal at any time through an issue.
- Automated dependency updates are performed by Dependabot and are not listed as people.

The automatically generated commit graph is also available at
[github.com/FossMec/foss-mec-library/graphs/contributors](https://github.com/FossMec/foss-mec-library/graphs/contributors).
It includes bot accounts; this page is the curated human list.

## Get listed

Make one focused contribution and open a pull request:

- [Add written notes](contribute/add-notes.md)
- [Upload a permitted file](contribute/upload-file.md)
- [Suggest an external resource](contribute/suggest-resource.md)
- Pick a [good first issue](https://github.com/FossMec/foss-mec-library/labels/good%20first%20issue)

Include your preferred credit name in the pull request. A maintainer will add you after the merge.
