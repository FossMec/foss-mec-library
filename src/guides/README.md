## Write a guide

Good guides come from problems you actually solved. A useful contribution:

- targets one reader and one outcome;
- uses short sections with runnable examples;
- explains the error message, not just the happy path;
- keeps commands copy-pasteable and avoids hidden assumptions;
- cites official documentation for anything version-specific.

Read [Add Written Notes](../contribute/add-notes.md) for the chapter conventions and how to update
`src/SUMMARY.md`. If you only want to fix a sentence, use the **Suggest an edit** pencil on the
page — no local setup required.
