# Open Source and Self-Learning

Open source is more than free code: it is a way of collaborating in public. These resources
explain the culture, the licensing and the mechanics of making a first contribution.

| Resource | Format | Description | Source / access |
| --- | --- | --- | --- |

## Learned something? Teach it

Self-learning is most durable when you turn it into a short, tested explanation. A good guide:

- starts from a real problem you hit;
- shows the exact commands or code;
- explains the error messages a beginner will meet;
- ends with a small exercise the reader can verify.

That is exactly the kind of original content this library wants. Read
[Add Written Notes](../contribute/add-notes.md) and open a pull request.
