# Git and GitHub

Version control is the core skill for contributing to open source. Start with the official book,
then practise in a sandbox before touching a real repository.

## Learn Git

| Resource | Format | Description | Source / access |
| --- | --- | --- | --- |
| [Pro Git, 2nd edition](https://git-scm.com/book/en/v2) | <span class="fmt fmt-book">Book</span> | The definitive free book. Chapters 1–3 cover repositories, commits and branching. | Scott Chacon and Ben Straub — free online, CC BY-NC-SA 3.0 |
| [Git reference manual](https://git-scm.com/docs) | <span class="fmt fmt-docs">Docs</span> | Official command reference when you need exact flags and behaviour. | Git project — free |
| [Learn Git Branching](https://learngitbranching.js.org/) | <span class="fmt fmt-course">Course</span> | Interactive visual exercises for branching, merging and rebasing. | Free, browser-based |
| [Oh My Git!](https://ohmygit.org/) | <span class="fmt fmt-game">Game</span> | An open-source game that teaches Git concepts through play. | Free and open source |
| [GitHub Git cheat sheet](https://education.github.com/git-cheat-sheet-education.pdf) | <span class="fmt fmt-pdf">PDF</span> | One-page reminder of everyday commands. | GitHub Education — free |

## Learn GitHub

| Resource | Format | Description | Source / access |
| --- | --- | --- | --- |
| [GitHub Docs](https://docs.github.com/en) | <span class="fmt fmt-docs">Docs</span> | Official documentation for repositories, issues, pull requests and Pages. | GitHub — free |
| [Git and GitHub learning resources](https://docs.github.com/en/get-started/start-your-journey/git-and-github-learning-resources) | <span class="fmt fmt-docs">Docs</span> | GitHub's curated entry point for beginners. | GitHub — free |
| [GitHub Skills](https://skills.github.com/) | <span class="fmt fmt-course">Course</span> | Short, hands-on courses that run inside a real repository. | GitHub — free |
