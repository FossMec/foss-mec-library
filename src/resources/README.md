## How links are chosen

Every entry should be:

1. **Free to access** without a paywall, trial or "request access" step.
2. **Authoritative** — the project's own documentation, the author's site, or a recognised
   educational institution.
3. **Alive** — checked when added; reported and fixed when it dies.
4. **Useful** — a short description explains *why* a student would open it.

Excluded: pirated textbooks, affiliate links, content dumps, AI-generated summaries presented as
official material, and anything locked behind an account the description calls free.
