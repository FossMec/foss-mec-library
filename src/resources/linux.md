# Linux and the Command Line

Almost every workshop, server and development tool assumes basic Linux comfort. These resources
take you from navigating directories to reading manual pages and writing small scripts.

## Start from zero

| Resource | Format | Description | Source / access |
| --- | --- | --- | --- |
| [The Linux Command Line](https://linuxcommand.org/tlcl.php) | <span class="fmt fmt-book">Book</span> | A patient, complete introduction by William Shotts. Free PDF and online edition. | Free, CC BY-NC-ND 3.0 |
| [Ubuntu command-line tutorial](https://ubuntu.com/tutorials/command-line-for-beginners) | <span class="fmt fmt-docs">Docs</span> | A short guided tour of the terminal for absolute beginners. | Canonical — free |
| [Linux man-pages](https://man7.org/linux/man-pages/) | <span class="fmt fmt-docs">Docs</span> | The reference for system calls and C library behaviour. Use it with `man`. | Free |
| [GNU Bash manual](https://www.gnu.org/software/bash/manual/) | <span class="fmt fmt-docs">Docs</span> | Official shell reference: expansions, builtins, job control. | GNU Project — free |

## Go deeper

| Resource | Format | Description | Source / access |
| --- | --- | --- | --- |
| [The Missing Semester](https://missing.csail.mit.edu/) | <span class="fmt fmt-course">Course</span> | MIT's practical course on the shell, editors, data wrangling and Git. | Free |
| [Advanced Bash-Scripting Guide](https://tldp.org/LDP/abs/html/) | <span class="fmt fmt-book">Book</span> | A long, example-driven reference for shell scripting. | Free |
| [GNU Coreutils manual](https://www.gnu.org/software/coreutils/manual/) | <span class="fmt fmt-docs">Docs</span> | Exact behaviour of `ls`, `cp`, `sort`, `find` and friends. | GNU Project — free |
| [explainshell](https://explainshell.com/) | <span class="fmt fmt-docs">Tool</span> | Paste a command and see each argument explained from the man pages. | Free |
| [ShellCheck](https://www.shellcheck.net/) | <span class="fmt fmt-docs">Tool</span> | Paste a script and catch common shell mistakes before running it. | Free and open source |
| [Bandit](https://overthewire.org/wargames/bandit/) | <span class="fmt fmt-course">Practice</span> | SSH-based wargame that teaches Linux commands through puzzles. | Free |

## Local practice

The [Linux Command Line guide](../guides/linux/) in this library is a short starter walkthrough of
the commands you need for workshops; it is not a student submission. For deeper practice, install a
Linux distribution in a virtual machine or use Windows Subsystem for Linux.
