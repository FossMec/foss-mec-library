# Programming

Free, official starting points for learning to program. Pick **one** language and one course,
then write code every week — collecting links is not practice.

## Python

| Resource | Format | Description | Source / access |
| --- | --- | --- | --- |
| [The Python Tutorial](https://docs.python.org/3/tutorial/) | <span class="fmt fmt-docs">Docs</span> | Official language tutorial, from data types to modules. | Python Software Foundation — free |
| [Python for Everybody](https://www.py4e.com/) | <span class="fmt fmt-course">Course</span> | Dr. Chuck's beginner course with videos, exercises and a free textbook. | Free |
| [Automate the Boring Stuff](https://automatetheboringstuff.com/) | <span class="fmt fmt-book">Book</span> | Practical Python for files, spreadsheets and small scripts. | Al Sweigart — free online |
